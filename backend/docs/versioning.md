# Versioning

- `0.8.3` is the current mobile baseline.
- `0.8.4-universal-foundation` is the backend universal resolver foundation.
- `0.8.5-phone-ready` adds LAN resolver settings, share-to-Clipora, capture fallback, and HLS file fallback.
- `0.8.6-carousel-launch` saves every clip from multi-media posts and uses the 3D rope Clipora launch mark.
